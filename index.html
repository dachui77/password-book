如何从 Chrome / Edge 导出：
1. 访问 chrome://settings/passwords
2. 点击 导出密码
3. 下载 CSV 文件后上传

如何从 Firefox 导出：
1. 访问 about:logins
2. 点击右上角 ⋮ → 导出登录名
3. 下载 CSV 文件后上传

选择 Firefox CSV 文件

如何从 Safari 导出：
1. Safari → 菜单 文件 → 导出 → 密码...
2. 下载 CSV 文件后上传

如何从 Bitwarden 导出：
1. 登录 bitwarden.com 或打开桌面应用
2. 设置 → 导出 → 选择 CSV 格式
3. 下载后上传
